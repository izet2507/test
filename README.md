# Агрегатор рецептур

Веб-приложение для технолога: хранение рецептур, спецификаций сырья и исходных файлов.

## Возможности

- **Рецептуры** — создание и редактирование с составом (ингредиенты) и технологическим процессом (этапы с температурой и временем)
- **Спецификации сырья** — карточки сырья с показателями качества, поставщиком, ГОСТ/ТУ, условиями хранения
- **Файлы** — загрузка любых файлов (PDF, Excel, Word, изображения) с привязкой к рецептурам или сырью
- **Поиск** — глобальный поиск по всем разделам через строку в шапке
- **Дашборд** — сводная статистика и последние изменения

## Запуск

### Установка зависимостей
```bash
npm run install:all
```

### Сборка frontend
```bash
npm run build
```

### Запуск (production)
```bash
npm start
# http://localhost:3001
```

### Разработка
```bash
# Terminal 1 — backend с hot reload
npm run dev:backend

# Terminal 2 — frontend dev server
npm run dev:frontend
# http://localhost:5173
```

## Стек

- **Backend**: Node.js, Express, SQLite (better-sqlite3), Multer
- **Frontend**: React 18, React Router, Vite
- **БД**: SQLite (файл `backend/data.db`)
- **Файлы**: хранятся в `backend/uploads/`
